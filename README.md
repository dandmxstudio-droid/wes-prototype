# Wes prototype

A design prototype of Wes, an everyday AI partner for people in a career transition, by Dan Mota.

- `/` plays six moments: the first night, coming back, a step session, a rough day, a new direction, and where Wes stops.
- `/design-system` is the Wes Design System (MVP).

Maya is a composite user. All data is illustrative. Designed in Claude Design.
